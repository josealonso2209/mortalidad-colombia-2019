# Insumos de la consolidación

El proceso `preparar_datos.py` utiliza estos archivos de origen:

- Anexo1.NoFetal2019_CE_15-03-23.xlsx
- Divipola_CE_.xlsx
- Anexo2.CodigosDeMuerte_CE_15-03-23.xlsx

Las huellas y los controles se registran en `../validacion_fuentes.json`. Los tres Excel se conservan en el paquete completo de fuentes. La ejecución de la aplicación utiliza las particiones y catálogos de este repositorio y no requiere cargar los Excel en cada arranque.

Metadatos estadísticos del DANE: https://microdatos.dane.gov.co/index.php/catalog/696
